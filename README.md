# Olá 👋 eu sou o João Vitor! 

## 🗨 Sobre Mim
Sou um Desenvolvedor Front-End Júnior apaixonado por criar interfaces web modernas, intuitivas e acessíveis. Minha expertise abrange tecnologias essenciais como HTML, CSS, JavaScript, TypeScript, React.js e Tailwind CSS. Tenho experiência sólida na integração com APIs RESTful para construir aplicações dinâmicas e sou proficiente em versionamento de código utilizando Git, GitHub e GitLab.

Participei ativamente de projetos desafiadores, aplicando metodologias ágeis (Scrum) e as melhores práticas de desenvolvimento para entregar soluções de alto impacto. Estou em constante busca por aprimoramento, aprofundando meus conhecimentos em tecnologias web e back-end para contribuir de forma significativa em cada novo desafio.
